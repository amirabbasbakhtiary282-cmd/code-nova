# SECURITY

## وضعیت فاز فعلی
- بدون احراز هویت واقعی
- بدون اتصال دیتابیس برای منطق فرانت
- بدون ذخیره کلید محرمانه در مخزن

## آزمایشگاه کد
- اجرای کد در iframe با `sandbox="allow-scripts"`
- انتقال runtime error و `console.log` از iframe به parent با `postMessage`

## هشدار مهم
پیاده‌سازی sandbox فعلی **برای اجرای کد نامطمئن کافی نیست** و فقط برای آموزش/دمو استفاده می‌شود.
برای نسخه production با کاربران واقعی، نیاز به runner ایزوله (process/container sandboxing، محدودیت منابع، و کنترل شبکه/سیستم‌فایل) در فاز بعدی وجود دارد.

## نکات تکمیلی
- RTL سراسری حفظ شده و نواحی کد به‌صورت LTR رندر می‌شوند.
- localStorage فقط داده‌های پیشرفت و draft کد را نگه می‌دارد.
